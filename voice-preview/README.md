# StackChan voice lab

Preview neural voices in the browser, then save one for the robot.

These are **not** a copyrighted cartoon voice. They are neural TTS voices you can hear immediately and later run on your home PC (same engine as this lab).

```bash
pip install edge-tts
cd voice-preview
npm install
npm run dev
```

Open http://127.0.0.1:43145, click **Play**, then **Use this**.
